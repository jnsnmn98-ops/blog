# 트렌드.zip 카드뉴스 편집·디자인 보완 지침

이 문서는 기존 `instagram/CARDNEWS_GUIDE.md`에 추가하는 보완 지침이다. 기존 제작 지침을 삭제하거나 전면 교체하지 않는다. 앞서 작성한 동일한 보완 지침이 있다면 이 문서로 교체해 중복 적용하지 않는다.

기존의 실제 이미지 사용, 사실 확인, 출처·권리 확인, 조사 기록, 파일 저장·전달 원칙은 유지한다. 이 문서는 **외부 조사, 독자와 주제에 맞는 테마, 사진 선택, 구성, 문구, 폰트와 검수**를 구체화한다.

파일 안의 예시 문구·색상·글꼴을 모든 작업에 기계적으로 반복하지 않는다.

---

## 1. 제작 전에 독자와 편집 방향을 정한다

자료를 바로 카드에 나누어 넣지 않는다. 먼저 다음을 정리한다.

- 누가 읽는가?
- 그 사람이 궁금해할 질문은 무엇인가?
- 발견·이해·비교·실행·구매·방문 중 무엇을 돕는가?
- 이번 소재만의 구체적인 특징은 무엇인가?
- 어떤 분위기가 독자·브랜드·사진에 어울리는가?

이를 바탕으로 **편집 방향과 디자인 방향을 각각 한 문장으로 정리**하고 작업 기록에 남긴다.

예시:

> 편집 방향: 작은 집에 놓을 식탁을 고르는 사람이 크기와 관리 방법을 판단하게 한다.  
> 디자인 방향: 실제 주거 공간 사진을 크게 쓰고, 아이보리와 우드색에 절제된 제목을 조합한다.

독자에게 답할 수 있는 질문을 중심으로 내용을 선택한다. 확보한 근거 없이 추천·우열·체감 효과를 주장하지 않는다.

## 2. 매 작업마다 주제에 맞는 외부 자료를 새로 확인한다

이전 작업의 레퍼런스는 보조 자료다. 색상이나 제품명만 바꾸기 위해 과거 조사만 재사용하지 않는다.

### 일반 카드뉴스 한 편의 기본 조사 기준

| 조사 대상 | 기본 기준 |
|---|---|
| 관련 계정·매체 | 서로 다른 3곳 이상. 가능하면 공식 브랜드·기관 1곳과 관련 전문 매체 포함 |
| 피드 표지·썸네일 | 관련 항목 15~25개 확인 |
| 캐러셀 본문 | 관련성 높은 3편 이상. 표지뿐 아니라 본문과 마지막 장까지 확인 |
| 공식 정보 | 카드에 넣을 날짜·가격·사양·조건 등 주요 주장별 확인 |
| 시각 자료 | 각 장의 역할에 맞는 이미지 확보. 가능한 경우 서로 다른 장면·상세·사용 맥락 3종 이상 |

이 수치는 작업을 위한 조사 기준이다. 관련성이 낮은 자료로 숫자만 채우지 않는다.

사용자가 폭넓은 분석을 요청하면 기존 지침의 **5개 이상 계정, 50~80개 피드 항목, 관련 캐러셀 4~6편** 목표를 적용한다.

접근 제한이나 관련 자료 부족으로 기준을 충족하지 못하면 다음을 기록한다.

- 실제 확인한 범위
- 확인하지 못한 자료와 이유
- 공식 웹사이트 등으로 대체 확인한 내용
- 제작 결과에 남는 한계

검색 요약만 읽은 것을 실제 화면 분석이라고 쓰지 않는다. 썸네일 확인과 캐러셀 전체 확인을 구분한다.

### 조사할 내용

색상과 폰트 이름만 수집하지 않는다.

- 표지가 무엇을 약속하는가?
- 첫 본문 장이 그 약속에 어떻게 답하는가?
- 넘길 때마다 어떤 새 정보나 장면을 주는가?
- 사진과 글의 비중은 어떻게 달라지는가?
- 글이 많은 장과 적은 장을 어떻게 배치하는가?
- 마지막 장은 어떤 정보나 행동으로 마무리하는가?
- 계정의 공통 요소와 주제별 변화는 무엇인가?

`reference-review.txt`에 **관찰 → 이번 작업의 결정 → 적용한 장**을 연결해 적는다.

공식 정보 확인과 디자인 레퍼런스 조사는 별개다. 디자인이 좋아 보이는 외부 게시물을 사실 확인의 최종 근거로 사용하지 않는다.

## 3. 주제·독자·브랜드에 맞는 테마를 선택한다

모든 주제에 같은 배경·글꼴·둥근 박스를 사용하지 않는다. 제작 전에 테마를 선택하고 사진과 원고에 맞춰 조정한다.

독자의 성별·연령·관심사는 참고하되, 성별만으로 디자인을 확정하지 않는다. **실제 대상 독자, 브랜드의 성격, 제품의 용도와 이미지**를 함께 판단한다.

예를 들어 밝고 귀여운 화장품과 차분한 고기능성 화장품은 구분한다. 컴퓨터 제품도 게이밍 기기와 업무용 기기를 구분한다.

### 테마 선택표

| 주제·상황 | 권장 분위기 | 색상 방향 | 폰트·형태 | 이미지 방향 |
|---|---|---|---|---|
| 발랄한 화장품·립·캐릭터 협업 | 밝고 귀엽고 생기 있게 | 크림·밝은 핑크·피치·제품색 | 둥근 제목 서체, 부드러운 모서리, 제한적인 스티커 | 제형·발색·사용 장면·제품 확대 |
| 피부 관리·기능성 화장품 | 깨끗하고 신뢰감 있게 | 화이트·연한 블루·차분한 브랜드색 | 단정한 고딕, 넓은 여백, 얇은 구분선 | 제형·도포·공식 설명 자료 |
| 프리미엄 뷰티·향수·주얼리 | 절제되고 감각적으로 | 아이보리·차콜·깊은 브랜드색 | 절제된 고딕 또는 명조, 장식 최소화 | 소재·빛·패키지·인물 화보 |
| 컴퓨터·마우스·키보드·업무용 기기 | 각지고 깔끔하며 기능적으로 | 화이트·차콜·쿨그레이, 포인트 1색 | 선명한 고딕, 직선과 정렬 중심 | 실제 사용·버튼·포트·화면·크기 비교 |
| 게이밍 기기·게임 | 역동적이고 선명하게 | 어두운 중립색과 게임·제품의 강조색 | 굵은 고딕, 필요한 곳에 각진 형태 | 실제 플레이·조작·효과 장면 |
| 가구·인테리어·생활용품 | 편안하고 자연스럽게 | 아이보리·샌드·우드·저채도색 | 담백한 고딕 또는 절제된 명조 | 실제 공간·소재·구조·크기 |
| 여행·맛집·전시 | 현장의 매력이 먼저 보이게 | 사진에서 추출한 색과 밝은 중립색 | 읽기 쉬운 제목, 사진 위 장식 최소화 | 실제 장소·음식·공간·동선 |
| 문화·캐릭터·가벼운 생활 정보 | 친근하고 경쾌하게 | 소재와 연결되는 밝은 색 | 둥근 제목과 단정한 본문 | 공식 스틸·캐릭터·실제 상황 |
| 뉴스·경제·실용 정보 | 명확하고 신뢰감 있게 | 중립색 중심, 강조색 1개 | 정보 위계가 분명한 고딕 | 실제 대상·자료·절차·도표 |

이 표는 출발점이다. 특정 성별이나 제품군을 이유로 무조건 핑크·검정·네온을 적용하지 않는다.

### 테마를 선택할 때 남길 기록

- 주 독자
- 선택한 분위기와 이유
- 기본색·강조색
- 제목·본문 서체
- 사진 처리 방식
- 사용할 장식과 그 역할
- 이번 작업에서 제외할 표현

‘화장품이므로 귀엽게’에서 끝내지 말고, 제품과 독자에게 왜 맞는지 설명한다.

## 4. 테마가 달라도 계정의 공통 요소는 유지한다

주제에 맞는 변화와 계정의 일관성을 함께 유지한다.

### 공통으로 유지할 요소

- 기본 본문 서체
- 기본 제목 서체와 정보 위계
- 좌우 여백과 정렬 기준
- 계정명·페이지 번호 위치
- 출처·크레딧 표기 방식
- 분류 라벨의 기본 형태

### 주제별로 바꿀 수 있는 요소

- 보조색과 사진의 분위기
- 사진 배치와 크롭
- 정보에 필요한 장 구성
- 선택적인 보조 제목 서체
- 소재와 연결되는 제한적인 장식

매번 전혀 다른 브랜드처럼 바꾸지 않는다. 반대로 계정의 공통색을 지키려고 모든 소재를 같은 색으로 덮지 않는다.

공용 제작 도구는 재사용해도 된다. 다만 준비된 템플릿에 자료를 억지로 맞추지 않는다.

## 5. 사진은 내용을 증명하거나 새로운 볼거리를 제공한다

이미지마다 다음 질문을 적용한다.

> “독자가 이 사진에서 직접 확인할 수 있는 것은 무엇인가?”

사진은 외형·특징·사용 맥락·상세·실행 방법 중 하나 이상을 보여줘야 한다.

| 설명할 내용 | 적합한 이미지 | 부족한 이미지 |
|---|---|---|
| 카메라의 촬영 특성 | 해당 모델의 공식 촬영 예시와 조건 | 휴대폰 외관만 반복 |
| 마우스의 조작과 형태 | 손에 쥔 모습·버튼·측면 | 정면 제품 사진만 반복 |
| 화장품 사용법 | 제형·도포 동작·공식 안내 | 패키지 사진만 반복 |
| 가구의 구조 | 단면·접합부·표면 확대 | 같은 전신 사진 |
| 앱의 기능 | 실제 기능 화면과 단계 | 일반 노트북 사진 |

사진이 주장을 보여주지 못하면 자료를 추가 확보하거나, 현재 사진이 보여주는 내용에 맞게 제목을 바꾸거나, 해당 주장을 제외한다.

같은 제품이 여러 장에 등장해도 장마다 보는 이유는 달라야 한다.

- 전체 모습 → 상세 → 사용 장면 → 크기 판단은 가능하다.
- 같은 사진 → 확대 → 숫자 추가로 장수를 채우는 방식은 피한다.
- 사진이 부족하면 장수를 줄인다.

## 6. 장마다 새 정보와 다른 호흡을 만든다

기존의 5~7장 기준을 유지하되, 소재가 짧으면 더 적게 구성한다.

모든 장을 `제목 + 사진 + 설명 박스 여러 개`로 만들지 않는다. 다음 구성을 필요한 만큼 조합한다.

- 큰 사진과 짧은 제목
- 사진만으로 전달되는 장
- 사진과 짧은 설명
- 같은 기준의 비교
- 숫자·절차·조건 정리
- 실제 사용 화면과 행동

다양하게 보이기 위해 불필요하게 배치를 바꾸지는 않는다. 내용의 역할에 따라 달라져야 한다.

제작 전에 각 장의 **역할·핵심 메시지·시각 자료·새 정보·구성 방식**을 정리한다. 앞 장과 새 정보가 거의 같으면 합치거나 삭제한다.

큰 제목·큰 숫자·큰 사진·여러 박스를 동시에 강조하지 않는다. 가장 먼저 볼 요소 하나를 정한다.

## 7. 제목과 문장은 구체적으로 쓴다

다른 제품에도 그대로 붙일 수 있는 홍보 문구를 반복하지 않는다.

- 경험을 손안 가득
- 특별함을 만나보세요
- 새로운 일상을 시작하세요
- 루틴에 더해 보세요
- 무조건 저장해야 할 정보

이런 표현 대신 이번 소재의 특징·변화·조건·독자의 질문을 담는다.

- 제목은 본문이 실제로 답하는 내용을 약속한다.
- 근거 없는 효과·우열·문제를 만들지 않는다.
- 같은 의미의 영문과 한글 제목을 모두 크게 쓰지 않는다.
- 영문 분류가 필요하면 작은 보조 표기로 사용한다.
- 해요체를 유지하되 모든 장을 권유형으로 끝내지 않는다.
- 마지막 행동 유도는 목적에 맞는 하나만 사용한다.

제품 소개라고 항상 구매를 권하지 않는다. 이해·비교·사용 방법이 목적이면 그 답을 주며 마무리한다.

## 8. 폰트는 분위기와 가독성을 함께 검토한다

### 서체 역할

- 기본 제목용 고딕 1종
- 기본 본문용 고딕 1종
- 테마에 필요한 경우 보조 서체 1종

같은 글꼴의 굵기를 달리 사용해도 된다. 사용 가능한 기존 폰트를 먼저 확인한다.

둥근 서체는 발랄한 소재의 제목에 선택적으로 사용한다. 긴 설명·제품 조건·통계 주석까지 장식 서체로 처리하지 않는다.

각진 고딕은 기술 제품의 명확한 인상을 만드는 데 사용할 수 있지만, 모든 문장을 지나치게 굵게 만들지 않는다.

### 1080×1350px 기준 시작 크기

| 역할 | 시작 크기 |
|---|---:|
| 표지 제목 | 80~104px |
| 본문 장 제목 | 60~84px |
| 핵심 설명 | 38~44px |
| 보조 설명 | 34~38px |
| 출처·주석 | 26~30px |

숫자는 검수의 시작점이다. 글꼴의 실제 크기·문장 길이·줄 수에 따라 조정한다.

- 내용이 맞지 않으면 문장을 줄이거나 구성을 바꾼다.
- 작은 글씨로 밀어 넣지 않는다.
- 중요한 조건을 주석으로만 보내지 않는다.
- 본문을 지나치게 가늘거나 옅게 처리하지 않는다.
- 밝은 테마에서도 연한 회색·파스텔 글씨의 대비를 확인한다.
- 어두운 테마에서도 작은 회색 글씨와 배경 패턴이 겹치지 않게 한다.

최종 이미지를 가로 360~390px로 축소해, 확대 없이 핵심 설명을 읽을 수 있는지 확인한다.

## 9. 장식에는 역할이 있어야 한다

둥근 테마라고 모든 요소에 둥근 박스·그림자·반짝이를 넣지 않는다. 각진 테마라고 모든 요소에 사선·네온 테두리·기계 패턴을 넣지 않는다.

장식이 다음 역할 중 무엇을 하는지 판단한다.

- 정보나 영역을 구분한다.
- 중요한 내용의 위치를 알려준다.
- 소재의 분위기를 보완한다.
- 계정의 공통 표기로 기능한다.

역할이 없다면 제거한다.

사진마다 테두리와 그림자를 붙이지 않는다. 사진을 화면 끝까지 크게 쓰거나 여백만으로 배치하는 방식도 검토한다.

가격이 핵심일 때만 크게 강조한다. 가격이 목적이 아닌 콘텐츠에서 가격 배지가 주제보다 먼저 보이지 않게 한다.

## 10. 최종 검수와 수정 순서

### 개별 장 검수

1. 첫눈에 볼 요소가 분명한가?
2. 제목과 사진이 같은 내용을 말하는가?
3. 사진이 설명의 증거나 새 볼거리를 제공하는가?
4. 독자·브랜드·소재에 맞는 테마인가?
5. 휴대폰 크기에서 본문이 읽히는가?
6. 장식이 대상과 정보보다 먼저 보이지 않는가?
7. 중요한 조건이 작은 주석에만 들어가 있지 않은가?

### 전체 흐름 검수

1. 처음 정한 독자의 질문에 답하는가?
2. 장마다 새 정보나 장면을 얻는가?
3. 같은 사진·문장·배치가 불필요하게 반복되지 않는가?
4. 글이 많은 장과 적은 장의 호흡이 자연스러운가?
5. 다른 주제와 나란히 놓아도 같은 계정으로 느껴지는가?
6. 마지막 장에서 약속한 답을 얻는가?
7. 조사 기록에 적은 결정이 실제 결과물에 반영됐는가?

### 수정 우선순위

1. 편집 방향과 핵심 메시지
2. 사진·자료의 적합성
3. 정보의 순서와 장 구성
4. 독자·소재에 맞는 테마
5. 글자 크기·대비·줄바꿈
6. 여백·장식·세부 마감

사진과 내용이 맞지 않는 문제를 배경색·테두리·폰트 변경만으로 해결했다고 판단하지 않는다.

## 11. 최종 전달과 기록

기존 PNG·전체 미리보기·표지 미리보기·캡션·출처·조사 기록·수정 가능한 원고·ZIP 전달 기준은 유지한다.

전체 미리보기뿐 아니라 휴대폰 크기로 축소한 대표 장도 확인한다.

최종 전달에는 다음을 짧게 정리한다.

- 대상 독자와 편집 방향
- 선택한 테마와 이유
- 사진·구성을 선택한 이유
- 실제 외부 조사 범위
- 검수 후 수정한 주요 사항
- 확보하지 못한 자료와 남은 한계

실제 조사·검수하지 않은 범위를 완료했다고 주장하지 않는다. 제작 요청과 게시·업로드 요청은 구분한다.
