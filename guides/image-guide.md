# 블로그 이미지 가이드

image-maker 에이전트가 읽는 가이드입니다.
대표 이미지와 본문 삽입 이미지를 만들 때 이 규격을 따릅니다.

## 대표 이미지 규격

- **크기:** 가로 1080px, 세로 1080px (1:1 정사각형)
- **배경:** 어두운 블루-퍼플 그라데이션 (`#1a1a2e` → `#16213e`)
- **메인 텍스트:** 글 제목 (큰 글씨, 흰색)
- **보조 텍스트:** 카테고리나 부제 (작은 글씨, 연한 회색)
- **정렬:** 모든 텍스트는 가로·세로 중앙 정렬
- **폰트:** Pretendard
- **액센트:** 좌상단에 작은 액센트 (도형, 코드 심볼, 또는 단순한 아이콘)

## 본문 삽입 이미지 종류

네 가지 중 글 내용에 맞게 선택합니다.

1. **비교 표:** 제품이나 방법을 나란히 비교할 때
2. **단계별 다이어그램:** 절차나 순서를 보여 줄 때
3. **핵심 포인트 카드:** 3~5개 요점을 정리할 때
4. **인용/강조 박스:** 중요한 한마디를 강조할 때

## 공통 규칙

- 모두 HTML + CSS로 만들고, Python으로 Playwright를 실행해 PNG로 캡처합니다.
- 배경 톤은 본문과 어울리게 맞춥니다 (AI/테크 분위기).
- 텍스트는 최대한 짧게 씁니다. 이미지는 보조 수단입니다.
- 코드 블록 스타일을 디자인 요소로 활용할 수 있습니다 (모노스페이스 폰트, 어두운 배경).
