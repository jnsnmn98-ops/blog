# 로지텍 G PRO X2 SUPERSTRIKE 광고 카드뉴스 기획

## 독자·편집 방향
- 독자: FPS·경쟁 게임을 하는 20~30대, 새 마우스를 고르는 중인 사람.
- 한 줄 메시지: "딸깍 스위치를 없애고 클릭을 센서로 읽는 마우스"라는 차이를 먼저 보여 주고, 숫자로 증명한 뒤 가격으로 끝내요.
- 광고 표기: 모든 카드 상단 '광고' 배지, 캡션 첫 줄 [광고]와 #광고.

## 테마 — 웅장한 장식 (Grand Arena)
- 배경: 거의 검정(#05070C)에 공식 이미지의 PCB 초록 빛을 이어받은 에너지 그린(#3CFFA0) 하나만 포인트로 사용.
- 장식과 역할
  - 코너 브래킷(조준선 모티프): 제품이 있는 자리를 가리키는 프레임. 사진 위에만 둠.
  - 빛줄기(광선): 마지막 카드에서 제품 뒤에 깔아 '등장' 느낌. 다른 카드에는 쓰지 않음.
  - 깎은 모서리 패널: 숫자·스펙을 묶는 칸.
  - 상단 HUD 라인과 페이지 번호: 순서를 알려 줌.
- 폰트: 제목 Black Han Sans(각지고 무거움), 본문 Apple SD Gothic Neo.

## 카드 구성 (6장)
1. 표지: 햅틱 기능 공식 이미지(검은 배경에 빛나는 마우스) + "스위치를 없앤 마우스"
2. HITS: 분해 이미지(초록 PCB) + 마이크로스위치 대신 센서·햅틱
3. 클릭 숫자: 정밀 클릭 이미지 + 최대 30ms / 작동 지점 10단계 / 리셋 5단계
4. 센서·무선: HERO 2 칩 이미지 + 44,000 DPI·888 IPS·88G·8000Hz
5. 본체: 측면 공식 이미지 + 61g·125×63.5×40mm·5버튼·최대 90시간
6. 가격: 상단 공식 이미지 + 광선 + 다나와 정품 최저가 245,000원(2026.11.05), 후속작 안내

## 피한 것
- 프로게이머 사진(실존 인물 초상)은 쓰지 않음.
- 설정 화면 이미지(구운 UI 글자)는 글자가 겹쳐 제외.
- "경험을 손안 가득" 같은 상투 문구 대신 기능·숫자로 문장 구성.
