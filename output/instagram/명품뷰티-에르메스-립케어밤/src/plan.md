# 기획 기록 — 루즈 에르메스 립 케어 밤
- 주 독자: 명품 뷰티 선물·첫 구매를 고민하는 20~30대
- 편집 방향: 립밤 하나가 어떤 효과·성분·케이스(리필)로 이 가격인지 판단하게 한다.
- 디자인 방향: 아이보리 + 에르메스 오렌지 얇은 선, 제품·텍스처·착용 사진을 장마다 다르게.
- 테마: #F4F0E9 / #28231E, 강조 #D9661F, 고운바탕 제목 + 산돌고딕 본문.
- 제외: 가격 배지, 과장 문구. 모델 사진은 공식 '착용 이미지' 1장만 효과 장에 사용(연예인 아님).
- 장 구성: 표지(엠보싱 캡) / 효과 수치 / 성분 / 리필 케이스 / 가격.
