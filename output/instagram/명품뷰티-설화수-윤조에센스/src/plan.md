# 기획 기록 — 설화수 윤조에센스 6세대
- 주 독자: 첫 단계 에센스를 고르는 20~30대(부모님 선물 포함)
- 편집 방향: 윤조에센스가 어떤 원료와 시험 결과를 가진 '첫 단계 에센스'인지, 지금 살 수 있는 용량과 가격까지 판단하게 한다.
- 디자인 방향: 따뜻한 아이보리 + 설화수 오렌지 얇은 선, 원료·텍스처 사진 중심, 한 장만 어두운 브라운으로 호흡 전환.
- 테마: #F6F0E6 / #34241A, 강조 #D65C1E, 고운바탕 제목 + 산돌고딕 본문.
- 제외: 연예인 모델(윤아) 사진, 글자가 박힌 상세 이미지 그대로 쓰기(문구 없는 사진 부분만 잘라 사용), 가격 배지.
- 장 구성: 표지 / 원료 / 시험 수치 / 6세대 역사·사용 단계 / 가격.
- '광고' 표기: 이번 3편은 협찬이 아닌 자체 소개 콘텐츠이므로 '광고' 라벨 대신 '제휴·후원 관계 아님'을 표기.
