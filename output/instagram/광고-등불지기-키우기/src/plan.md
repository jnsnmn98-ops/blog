# 등불지기 키우기 광고 카드뉴스 기획 (2026-11-11)

## 독자·방향
- 독자: 방치형·픽셀 RPG를 좋아하고, 앱 설치 없이 가볍게 해 볼 게임을 찾는 10~30대.
- 편집 방향: "설치 없이 브라우저에서 바로, 꺼 둬도 자라는 픽셀 방치형 RPG"라는 차이를 실제 화면으로 보여 주고, 무한의 탑 질문과 주소 하나로 끝낸다.
- 디자인 방향: 게임의 밤하늘 남색·보라 + 계정 기본 라임 강조, 게임 화면을 크게(전면·네온 테두리 패널), 제목 Black Han Sans.

## 카드(6장)
1. 표지 — 시작 화면(로고·주인공) 전면 + "설치 없이 바로 하는 / 픽셀 방치형 RPG"
2. 자동 사냥 — 7-9 별 연못 전투 화면 + 손 떼면 자동, 끌면 조이스틱
3. 오프라인 보상 — '다녀오셨군요!' 창 + 기본 최대 8시간(예시 표기)
4. 스킬 상세 — 스킬 상세 카드 + 1회 피해·조합 시너지·추천
5. 레이드 — 십자 바닥 경고 화면 + 보스 패턴 피하기
6. 무한의 탑 — 탑 화면 + "이번 주엔 몇 층까지 갈까요?" + 주소(행동 유도 하나)

## 피한 것
- 성과 수치(이용자 수·순위)·'최고' 같은 근거 없는 표현, '다운로드'(스토어 출시 안 함).
- 같은 배치 반복: 표지 전면 / 위 제목+큰 화면 패널을 화면 성격에 맞게 크기 조절.
