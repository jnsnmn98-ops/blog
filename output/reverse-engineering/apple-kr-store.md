# Apple Store 온라인(한국) 역설계도

- 대상: https://www.apple.com/kr/store (광고 추적 파라미터는 제거하고 분석)
- 분석일: 2026-11-05
- 방법: 페이지 텍스트·구조 읽기, 브라우저 개발자 도구로 글꼴·색·크기 측정(데스크톱 1024px, 모바일 375px)
- 범위: 화면 구조, 디자인 규칙, 문구 전략, 기술 구성. 내부 서버·결제 시스템은 공개 정보가 아니라 다루지 않아요.

## 1. 한 줄 요약

**"카드를 가로로 넘기는 선반(shelf)을 위에서 아래로 쌓은 쇼핑 홈"**이에요.
모든 섹션이 같은 틀(굵은 제목 + 회색 부제 → 가로 스크롤 카드 줄)을 반복해서, 정보가 많아도 복잡해 보이지 않아요.

## 3. 반복되는 핵심 틀: "선반(shelf)"

```
[섹션 제목]  최신 제품.  지금 바로 여기에서.
             └ 검정 28px/600 └ 회색 28px/600 (같은 줄, 색만 다름)

[카드][카드][카드][카드] →   (가로 스크롤, 카드 간격 10px, 왼쪽 여백 22px)
                     ( ◀ ▶ 둥근 화살표 버튼 45×45px )
```

- 클래스 이름으로 보면 `rs-cardsshelf`(선반) 안에 `rf-cards-scroller`(가로 스크롤러)가 들어 있어요.
- 선반 종류 3가지:
  - 일반 선반: 높이 약 627px, 큰 카드
  - 반 크기 선반(`rs-halfsize-cardsshelf`): 카드 313×240px, 서비스·도움말용
  - 제품 내비 선반: 아이콘 카드
- **제목 공식**: `[주제 단어]. [이유·혜택 한 문장].`
  - 예: "액세서리. 당신의 최애 제품과 찰떡궁합인 필수템."
  - 앞은 검정, 뒤는 회색이에요. 한 줄 안에서 "무엇"과 "왜"를 동시에 말해요.

## 4. 제품 카드 해부 (최신 제품 선반)

| 요소 | 값 | 역할 |
|---|---|---|
| 카드 크기 | 400×500px (4:5), 모바일 309×450px | 사진을 크게 보여 줌 |
| 모서리 | 18px 둥글게 | 부드러운 인상 |
| 그림자 | `rgba(0,0,0,0.08) 2px 4px 12px` | 아주 옅게 띄움 |
| 배경 | 제품마다 검정 또는 흰색 | 제품 색과 대비 |
| 눈썹 문구 | "NEW" 12px/600, 주황(어두운 카드 #FF791B, 밝은 카드 #B64400) | 새것 표시 |
| 제품명 | 28px/600 | 한눈에 식별 |
| 한 줄 카피 | 14px/600 | 감성 한 줄 |
| 가격 | "₩1,990,000부터" 14px/600 | 진입 가격만 노출 |
| 이미지 | 800×1000px(2배 해상도), 지연 로딩 | 레티나 대응 |

**카드 문구 공식**: `NEW` → `제품명` → `한 줄 카피(8~20자)` → `₩가격부터`

- 카피는 기능 나열보다 말장난과 감성 위주예요.
  - "오색. 찬란."(iPhone 17)
  - "오오오오오. 파워."(iPad Pro)
  - "반가워요, 반가워요."(iPhone Duo, 두 개라는 의미)
- 숫자 근거는 각주로 내려보내고, 카드에는 주장만 남겨요.

## 6. 문구(카피) 전략

1. **두 톤 제목**: 검정 "주제." + 회색 "이유." 구조로 모든 섹션을 통일했어요.
2. **짧은 마침표 문장**: "꿈의 화면." "작지 않은 놀라움."처럼 2~4단어로 끊어요.
3. **가격은 '부터'**: 최저 진입가만 보여 줘서 비싸 보이는 인상을 줄여요.
4. **불안 해소 문구를 곳곳에 배치**: 무이자 할부(리본), 보상 판매, 무료 배송, 반품 링크.
5. **각주로 신뢰 확보**: 과장처럼 보일 수 있는 주장에 기호 각주(※, ¶, §, ◊, ∆)를 달아요.
6. **한국형 표현 현지화**: "최애", "찰떡궁합", "필수템"처럼 국내 커뮤니티 말투를 섞었어요.

## 7. 인터랙션·기술 구성

| 항목 | 내용 |
|---|---|
| 화면 구성 | React 기반(`react.production.min.js`, `store-home.js`) |
| 공통 내비 | `ac-globalnav` 모듈. 애플 사이트 전체가 같은 상단 바를 공유 |
| 가로 스크롤 | 카드 줄을 화살표 버튼으로 넘김. 키보드·화면 낭독기용 "이전/다음" 숨김 텍스트 제공 |
| 이미지 | 2배 해상도, 지연 로딩(`loading=auto`), 이미지 서버에서 크기별 변환 |
| 반응형 | 1024px → 375px에서 카드 400×500 → 309×450, 제목 80 → 48px |
| 접근성 | "새 창에서 열림" 안내, 이전/다음 버튼 라벨, 각주 링크 |
| 분석 | Adobe Analytics(`AppMeasurement.js`, `ActivityMap.js`)로 클릭 추적 |
| 유입 추적 | URL의 `afid`, `cid` 파라미터로 광고(구글 검색 브랜드 키워드) 유입을 구분 |

## 8. 그대로 가져다 쓸 수 있는 설계 원칙

| 원칙 | 우리 작업(블로그·카드뉴스·랜딩)에 적용 |
|---|---|
| 한 가지 틀을 반복 | 섹션마다 "굵은 제목 + 회색 이유 + 카드 줄"로 통일 |
| 깔때기 순서 | 신제품 → 추가 구매 → 불안 해소 → 혜택 → 할인 → 고객 업무 |
| 카드 4:5 비율 | 인스타 카드뉴스(1080×1350)와 같은 비율. 제품 카드를 그대로 카드뉴스 표지로 활용 가능 |
| 가격은 '부터' | 세트·옵션 상품은 최저가만 전면에, 상세는 다음 장으로 |
| 주장은 짧게, 근거는 각주 | 카드에는 한 줄, 출처·조건은 하단 작은 글씨 |
| 색은 3개만 | 배경 옅은 회색, 글자 거의 검정, 링크 파랑 + 강조색 하나 |
| 잘린 카드로 다음 유도 | 캐러셀 첫 장에서 다음 장 일부를 보여 주는 구성 |
